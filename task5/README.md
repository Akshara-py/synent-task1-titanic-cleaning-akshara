# Sales Data Analysis

## Project Overview

This project analyzes sales data from a retail Superstore dataset.

## Objective

To identify sales trends, top-selling products, and profit performance across categories.

## Dataset

Superstore Dataset

Source:
Kaggle Superstore Dataset

## Analysis Performed

### Monthly Revenue Trend
Analyzed sales over time to identify revenue patterns.

### Top Selling Products
Identified the 10 products with the highest sales.

### Profit by Category
Compared profitability across product categories.

## Technologies Used

- Python
- Pandas
- Matplotlib
- VS Code
