# Titanic Data Cleaning and Preprocessing

## Project Overview

This project focuses on cleaning and preprocessing the Titanic dataset to prepare it for analysis.

## Objective

The goal is to transform raw data into a clean and structured dataset by handling missing values, removing duplicates, and renaming columns.

## Dataset

Titanic Dataset

Source:
https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv

## Tasks Performed

- Handled missing values
- Filled Age column using median
- Filled Embarked column using mode
- Replaced missing Cabin values with "Unknown"
- Removed duplicate rows
- Renamed columns for readability
- Exported cleaned dataset

## Technologies Used

- Python
- Pandas
- VS Code
