# Customer Segmentation Using K-Means Clustering

## Project Overview

This project uses K-Means Clustering to segment customers based on annual income and spending score.

## Objective

Identify different groups of customers to support targeted marketing strategies.

## Dataset

Mall Customers Dataset

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-Learn
- VS Code

## Analysis Performed

- Data Loading
- Feature Selection
- Elbow Method
- K-Means Clustering
- Cluster Visualization

## Output Files

- customer_clusters.csv
- customer_segments.png
- elbow_method.png

## Results

Successfully segmented customers into 5 clusters based on income and spending behavior.
