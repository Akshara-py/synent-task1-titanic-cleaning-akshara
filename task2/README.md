# Iris Dataset Visualization

## Project Overview

This project performs Exploratory Data Analysis (EDA) and visualization on the Iris dataset.

## Objective

To understand relationships between features and visualize species differences using charts.

## Dataset

Iris Dataset

Loaded using Seaborn library.

## Visualizations

### Histogram
Shows the distribution of sepal length.

### Scatter Plot
Shows relationship between sepal length and petal length.

### Bar Chart
Shows average sepal length for each species.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## Files

- iris_visualization.py

Successfully generated visualizations and identified differences among Iris species.
